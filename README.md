# Cairn

> 旅人在荒野中堆起石块，标记走过的路。  
> Cairn 做同样的事——记住你的文件去了哪里。

将任意文件拖入屏幕边缘，Cairn 自动完成解析、标签化与归档。  
无弹窗，无打断，一切在后台静默发生。

---

## 它做什么

1. **拖放触发** — 将文件拖到屏幕边缘的透明区域
2. **自动解析** — 提取文本内容、元数据、链接
3. **规则匹配** — 按你配置的规则打标签、移动、归档
4. **写入索引** — 支持全文检索，归档即可找回

## 快速开始

**环境要求**

- Python 3.11+
- Windows 10（当前优先支持平台）

**安装**

```bash
git clone https://github.com/771835/cairn.git
cd cairn
pip install -r requirements.txt
python main.py
```

启动后，屏幕右侧边缘会出现一条半透明蓝色细条。  
将任意文件拖入该区域即可触发处理。

## 规则配置

Cairn 使用 `.nxs` 格式的规则脚本，目前仅支持直接编写的方式。

```
rule "归档 PDF".10 (ext == ".pdf") => {
    tag "paper"
    store
    stop
}
```

右键托盘图标 → 打开配置，可通过图形界面管理规则。  
GUI 与规则文件实时双向同步。

## 插件

Cairn 的解析器、规则条件、规则动作扩展均以插件形式实现。  
第三方插件与官方插件权限完全对等。

```
plugins/
└── my_plugin/
    ├── plugin.json
    └── main.py
```

# 当前严重问题

项目目前对同路径不同哈希的文件存在较为严重的问题，因此请勿将极其重要的文件存入或将极其依赖结构的文件存入  
若项目本体无法加载及还原文件，请使用[cairn_restore脚本](/cairn_restore.py)尝试恢复，该脚本不依赖其他项目部分，仅需要`Python 3.10+`
